# Improve mobile performance and guide discovery while preserving bookings

The published site loads duplicate legacy scripts and has incorrectly cased gallery assets, while its homepage differs from the old repository. This branch reconciles the published source, replaces the client plugins with a responsive static design and native navigation/gallery, and removes unused libraries, icon fonts and duplicate audit artifacts. Existing page URLs, original article/policy text, Booksy/store destinations, contacts and form recipient are preserved.

Adds a categorized guide collection at `barber-tips.html`, native topic navigation, reading estimates and related guides ordered by subject. Responsive WebP variants match card widths; article images retain their intrinsic size. Editorial metadata and HTML/CSS/JS/image budgets are centralized under `content/`; static checks reject size/dependency regressions and orphan assets. Includes canonical/metadata, sitemap/robots and local-business/article/breadcrumb/collection JSON-LD. Content-hashed images use immutable caching; document assets revalidate for safe updates and rollback.

AdSense publisher, ads.txt and loader scope are preserved; the new collection, legal pages and 404 do not load ads. No manual units or account settings were changed. The consent-gated booking event is off by default and does not establish compliance for inherited Google tags. Private AdSense financial/session data is excluded from this public branch.

Validation: deterministic build and static checks pass for 13 HTML documents, 437 local references, 36 Booksy links and zero orphan assets. Browser checks pass at 320/390/768/1440, covering source-text preservation, topic anchors, same-category related guides, correct image sizes, keyboard gallery/menu, no-JS fallback and stubbed measurement. No forms, appointments, real ads or external analytics events were generated.

Final sequential local Lighthouse performance (mobile/desktop): homepage 98/100, guide collection 99/100, measured beard article 99/100. CLS is 0; automated accessibility, best practices and SEO are 100 in all six runs. These isolated localhost results omit ads/CMP/Analytics and do not establish production CWV, INP, ranking, conversion or revenue gains.
